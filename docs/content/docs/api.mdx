## useHighlightPopover

Returns the state of the nearest `HighlightPopover`. Throws an error outside a `HighlightPopover`.

## Types

The package exports these types:

```ts
import type {
  HighlightPopoverProps,
  HighlightPopoverContextValue,
  PopoverRenderProps,
  PopoverPosition,
  PopoverAlignment,
  PopoverPlacement,
} from "@omsimos/react-highlight-popover";
```
