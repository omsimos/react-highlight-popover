---
title: Migrating from v1
description: Breaking changes in v2 and how to update.
---

v2 fixes several bugs, adds positioning features, and requires a few changes.

```npm
npm i @omsimos/react-highlight-popover@2
```

## Breaking changes

### React 18 or later

React 17 is no longer supported.

### Offset direction

A positive `offset.y` now moves the popover away from the selection. In v1, it moved the popover up. Flip the sign:

```diff
- <HighlightPopover offset={{ y: -10 }} renderPopover={renderPopover}>
+ <HighlightPopover offset={{ y: 10 }} renderPopover={renderPopover}>
```

`offset.x` now always moves the popover right. In v1, it moved left with `alignment="right"`.

### Position

`position` is now the popover's top-left corner. In v1, it was the anchor point under the selection, and the popover was centered with a CSS transform.

### Showing the popover

The popover now waits for the pointer to be released. Add `showWhileSelecting` to keep the v1 behavior.

`onSelectionStart` now fires when a selection begins, before `onSelectionEnd`. In v1, it fired together with `onPopoverShow`.

### ARIA attributes

The popover no longer has `role="tooltip"` and `aria-live="polite"`. Pass them with `popoverProps` if you need them. See [Accessibility](/docs/accessibility).

### Package output

The build output is now `dist/index.mjs`. Import from the package name, since deep imports into `dist` will break.

## New defaults

These are on by default, and you can turn them off:

- **Collision handling.** The popover flips and shifts to stay in the viewport. Set `avoidCollisions={false}` to turn this off.
- **Escape to dismiss.** Set `closeOnEscape={false}` to turn this off.

## New features

- `placement`, `collisionPadding`, `portal`, and `popoverProps` props
- `range` and `placement` in `renderPopover`, and `selectionRange` and `placement` in `useHighlightPopover`
- A `data-placement` attribute on the popover element
- The popover follows the selection on scroll, resize, and reflow
- Exported types
- `"use client"` for Server Components
